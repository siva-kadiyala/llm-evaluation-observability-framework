# LLM Evaluation & Observability Framework

A Python project for testing LLM responses, comparing prompts, and tracking basic performance metrics.

## What this project does

When building an application with a large language model, it is important to check whether the responses are useful and consistent. This project is intended to make those checks easier to run and compare.

The project will include:

- A set of test questions and expected answers
- Basic checks for LLM response quality
- Comparisons between prompt versions and model outputs
- Tracking for response time, token usage, and errors
- Reports that help identify changes in evaluation results

## Tech Stack
